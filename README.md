# Kit Endomarketing

Modelos para planejar, executar e medir campanhas de comunicação interna, alinhadas à cultura da empresa e ao perfil dos colaboradores.

> *Entender profundamente para comunicar com precisão.*

## Conteúdo

| Arquivo | Uso |
|---|---|
| [`modelo-campanha-interna.md`](modelo-campanha-interna.md) | Plano de uma campanha interna, do objetivo aos indicadores |
| [`calendario-anual.md`](calendario-anual.md) | Estrutura de calendário de comunicação interna |
| [`pesquisa-de-clima.md`](pesquisa-de-clima.md) | Roteiro base de pesquisa rápida (pulso) com colaboradores |

## Princípios

- **Cultura antes da campanha:** entender como a empresa realmente funciona, não só como se descreve
- **Perfis diferentes, canais diferentes:** escritório, fábrica, campo e remoto consomem informação de formas distintas
- **Online e offline juntos:** mural, reunião de turno e rádio interna valem tanto quanto e-mail e app
- **Escuta antes e depois:** toda campanha começa e termina com dados dos colaboradores
- **Privacidade:** respostas de pesquisa são anônimas e tratadas conforme a LGPD

## Como usar

1. Comece pela pesquisa de clima para ter uma linha de base.
2. Monte a campanha com o modelo, usando os resultados da pesquisa.
3. Encaixe as ações no calendário anual.
4. Repita a pesquisa ao final para medir a mudança.
